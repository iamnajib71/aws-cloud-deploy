# Reporting security issues

Do not post credentials, exploitable details or private cloud data in a public issue. Use GitHub's **Security → Report a vulnerability** where available. Otherwise contact the maintainer through the profile linked in the README to arrange a private report.

Include affected commit, reproduction steps with fictional data and the impact. Never attach Terraform state or live credentials. Current security boundaries and accepted scanner exceptions are documented in [docs/security.md](docs/security.md).

This is a preview starter. Live AWS deployment evidence is pending; it is not presented as a hardened production platform.
